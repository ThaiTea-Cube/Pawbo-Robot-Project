# สลับหน้าจอ TFT สองจอด้วย Touch Sensor

สเก็ตช์นี้ใช้ ESP32 บน Massmore, จอ ST7789 SPI 240×240 สองจอ และ Touch Sensor ดิจิทัล 3 ขา เช่น TTP223 แบบ Direct จอทั้งสองหมุนภาพ 180°

## ต่อสาย

ใช้ [ผังสายจอจาก tft-test](../tft-test/README.md) โดยจอซ้ายใช้ `CS = GPIO32` และจอขวาใช้ `CS = GPIO33` จากมุมมองด้านหน้าหุ่นยนต์

| ขา Touch Sensor | ขาบน Massmore ESP32 |
| --- | --- |
| `VCC` / `VDD` | `3V3` |
| `GND` | `GND` ร่วมกับจอ |
| `OUT` / `SIG` / `I/O` | ขาสัญญาณ `IO7 / GPIO35` |

ต่อปุ่มกดแบบปกติเปิด โดยให้ขาหนึ่งลง GND และอีกขาเข้าตามตาราง โค้ดเปิดตัวต้านทานดึงขึ้นภายใน ESP32

| ปุ่ม | ขา ESP32 |
| --- | --- |
| ซ้าย | `GPIO25 / IO1` |
| ขวา | `GPIO27 / M1_IN1` |

เว้นขา GPIO25 จากแอมป์แอนะล็อก และเว้น GPIO27 จากวงจรควบคุมมอเตอร์ระหว่างใช้งานปุ่ม สำหรับเสียงปลุก ใช้ [DFPlayer ที่เคยทดสอบ](../dfplayer-test/README.md) โดยให้ `TX → GPIO13` และ `RX ← GPIO14` ผ่านตัวต้านทาน 1 kΩ ต่อ GND ร่วม จ่าย 5V ให้ DFPlayer และใส่ `/0001.mp3` เป็นไฟล์เสียงแรกบน microSD

## ตั้งค่า Wi-Fi และอัปโหลด

1. ใน `touch-tft-test.ino` ค่าเริ่มต้นคือ `WIFI_SSID = "KMUTT-Secure"` (Wi-Fi 2.4 GHz แบบ WPA2-Enterprise, PEAP/MSCHAPv2) ใส่บัญชีของคุณใน `WIFI_USERNAME` และ `WIFI_PASSWORD` ในเครื่องตัวเอง ถ้า `WIFI_IDENTITY` ว่าง โค้ดจะใช้ค่าเดียวกับชื่อผู้ใช้ตามรูปแบบในคู่มือ KMUTT ถ้า KMUTT IT ให้ใบรับรอง CA สำหรับ RADIUS ให้ใส่ PEM ใน `WIFI_CA_PEM` โดยเก็บบรรทัดขึ้นต้นและลงท้ายของใบรับรองไว้
2. ติดตั้ง **Adafruit ST7735 and ST7789 Library**, **Adafruit GFX Library** และ **DFRobotDFPlayerMini** จากนั้นอัปโหลด เปิด Serial Monitor ที่ **115200 baud** และเว้นนิ้วจากแผ่นเซ็นเซอร์ช่วงเปิดเครื่อง

## เปลี่ยนหน้าและแบบตา

- แตะสั้นแล้วปล่อยเพื่อไปหน้าถัดไปตามลำดับ **ตา → เวลาและวันที่ → นาฬิกาปลุก → ตา**
- ปุ่มซ้ายย้อนหน้า ปุ่มขวาไปหน้าถัดไป ภาพเลื่อนคนละทิศตามปุ่ม
- ที่หน้าตา แตะค้างประมาณ **0.7 วินาที** แล้วปล่อยเพื่อวนทีละแบบตามลำดับ Widow Core, Ion Hunter, Void Eclipse, Kitsune Ember, Ghost Sonar และ Glitch Hex

## ตั้งนาฬิกาปลุกทุกวัน

1. ไปหน้าปลุกแล้วแตะค้างเพื่อเริ่มแก้ไข ค่าเริ่มต้นคือ 07:00 และปิดอยู่
2. ใช้ปุ่มซ้ายลดและปุ่มขวาเพิ่ม แตะสั้นเพื่อเลื่อนช่อง **ชั่วโมง → นาที → ON/OFF** เมื่อเลือก ON/OFF ให้กดปุ่มใดปุ่มหนึ่งเพื่อสลับสถานะ
   กดปุ่มซ้ายหรือขวาค้างเพื่อปรับชั่วโมงหรือนาทีต่อเนื่อง ตัวเลขจะวิ่งเร็วขึ้นเมื่อกดค้างนานกว่าประมาณ 1.2 วินาที
3. แตะค้างอีกครั้งเพื่อบันทึกเวลาและสถานะลงแฟลช ESP32
4. เมื่อถึงเวลาท้องถิ่นและเปิดปลุกไว้ จอขึ้น `WAKE UP!` และ DFPlayer เล่นไฟล์แรกวนจนแตะหรือกดปุ่มหยุด เสียงหยุดเองหลัง 60 วินาที

ESP32 ต้องเปิดอยู่และได้รับเวลาจาก NTP หลังบูตเพื่อปลุกตามเวลา ค่าปลุกที่บันทึกยังอยู่หลังรีสตาร์ต

เวลาแสดงเป็น UTC+7 โดยใช้ `time.navy.mi.th` ของกรมอุทกศาสตร์ กองทัพเรือเป็นค่าเริ่มต้น ยังไม่ได้ยืนยัน hostname สาธารณะของกองทัพบก หากมี hostname ของกองทัพบกที่ใช้งานได้ ให้ใส่ใน `NTP_SERVER` จะแสดง `--:--:--` จนกว่าจะซิงก์เวลาได้ ทุกหน้ายังเลื่อนได้ขณะรอ Wi-Fi [เอกสารบริการเทียบเวลาของกรมอุทกศาสตร์](https://www.hydro.navy.mi.th/hydrokm/download/55_timestandard.pdf)

Serial Monitor ขึ้น `Wi-Fi connected` เมื่อเชื่อมกับมหาวิทยาลัยแล้ว และขึ้น `Clock synchronized` เมื่อได้เวลา ถ้า Wi-Fi ต่อได้แต่เวลายังเป็นขีด ให้ตรวจว่ามหาวิทยาลัยอนุญาต UDP พอร์ต 123 หรือใช้ NTP Server ที่ฝ่าย IT ระบุ เมื่อเว้น `WIFI_CA_PEM` ว่าง สเก็ตช์จะเรียก PEAP โดยไม่ส่ง CA ที่เจาะจงให้ไลบรารี เช่นเดียวกับตัวอย่างตั้งค่าของ KMUTT [คู่มือ KMUTT-Secure](https://cc.kmutt.ac.th/en/wifi.html) · [ตัวอย่าง Enterprise ของ Espressif](https://github.com/espressif/arduino-esp32/tree/master/libraries/WiFi/examples/WiFiClientEnterprise)

รอให้เลื่อนจบก่อนแตะหรือกดปุ่มอีกครั้ง หากสัญญาณแตะกลับด้าน ให้เปลี่ยน `TOUCH_ACTIVE_LEVEL` เป็น `LOW` ให้ตรงกับโมดูล
