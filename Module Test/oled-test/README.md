# ทดสอบ OLED SSD1306 สองจอพร้อมกัน

สเก็ตช์นี้ใช้ OLED แบบ I²C 4 ขา ขนาด 128×64 ตามผัง Massmore และใช้ I²C ของ ESP32 คนละบัสสำหรับแต่ละจอ ทั้งสองจอจึงใช้ที่อยู่ `0x3C` เหมือนกันได้ โค้ดตรวจทั้ง `0x3C` และ `0x3D` แยกกัน

## ต่อสายกับ Massmore 38-pin

ปิดไฟก่อนต่อสาย ตรวจลำดับขาจากป้ายของจอแต่ละตัว หากป้ายเขียน `SCK` บนจอ I²C 4 ขา ให้ต่อเป็น `SCL`

| ขาบน OLED | จอ 1 | จอ 2 |
| --- | --- | --- |
| `GND` | `GND` | `GND` |
| `VCC / VDD` | `3V3` | `3V3` |
| `SDA` | `GPIO21` | `GPIO32` |
| `SCL / SCK` | `GPIO22` | `GPIO33` |

- **จอ 1** ใช้หัว I²C ด้านขวาของ Massmore ที่พิมพ์ว่า `GND 3V3 22 21` ถ้า PCA9685 ยังเสียบอยู่ ให้แยกสายขนานที่ GPIO21/22 ได้เมื่อ PCA9685 ใช้ที่อยู่ `0x40`
- **จอ 2** ใช้ขา GPIO32 และ GPIO33 บนแถวขา ESP32 หรือเฉพาะขา **สัญญาณ** ของหัว `Servo2` และ `Servo3` ตามลำดับ ดึงไฟจอจากขาที่พิมพ์ `3V3` ห้ามใช้ขาไฟบวกของหัว Servo มาจ่ายไฟจอ เว้นขา Servo2/Servo3 สำหรับจอขณะทดสอบ
- ใช้กราวด์ร่วมกันระหว่างจอทั้งสองกับ ESP32 โดยให้สาย SDA/SCL ของสองบัสแยกกัน

## อัปโหลดและตรวจผล

1. ใน Arduino IDE ติดตั้ง **Adafruit SSD1306** และ **Adafruit GFX Library** ผ่าน Library Manager รวมถึง dependencies ที่ IDE เสนอ
2. เปิด `oled-test.ino` เลือกบอร์ด ESP32 และพอร์ต USB แล้วอัปโหลด เปิด Serial Monitor ที่ **115200 baud** และกด EN/RESET หากพลาดข้อความเริ่มต้น
3. ตรวจว่าจอแรกขึ้น **OLED 1** จอที่สองขึ้น **OLED 2** ทั้งสองจอแสดงกรอบครบสี่ด้าน ตัวเลขเฟรมเดินทุกวินาที และแถบด้านล่างวิ่งคนละทิศ ใช้ผลที่เห็นจริงเพื่อยืนยันว่าจอทั้งสองผ่าน
4. ถ้าขึ้น `no ACK` ให้ตรวจไฟ กราวด์ และสาย SDA/SCL ของจอตามหมายเลขใน log ถ้าขึ้น `I2C ACK` แต่จอยังดำหรือภาพเพี้ยน ให้ตรวจว่าจอเป็น SSD1306 128×64 โดยดูสเปกโมดูล
