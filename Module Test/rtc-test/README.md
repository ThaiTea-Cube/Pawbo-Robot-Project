# ทดสอบโมดูล RTC กับ ESP32

สเก็ตช์นี้ตั้งค่าสำหรับ **DS1302** ตามขา `CLK`, `DAT`, `RST` ที่แจ้งไว้ ให้ดูชื่อบนชิปเพื่อยืนยันรุ่น

## ต่อสาย

ปิดไฟก่อนต่อสาย ใช้สายจัมเปอร์จากขา GPIO ที่ระบุบนบอร์ด Massmore

| ขา RTC | ขาบน Massmore ESP32 |
| --- | --- |
| `GND` | `GND` |
| `VCC` | `3V3` |
| `CLK` / `SCLK` | `GPIO16` |
| `DAT` / `I/O` | `GPIO17` |
| `RST` / `CE` | `GPIO19` |

ขา `RST` บนโมดูลทำหน้าที่เลือกชิป (CE) บน Massmore GPIO16/17 แชร์กับ `M2_IN1/M2_IN2` และ GPIO19 แชร์กับขาสัญญาณ `Servo1` เว้นอุปกรณ์ที่ใช้สามขานี้ระหว่างทดสอบ

## ตั้งเวลาและทดสอบแบตสำรอง

1. ติดตั้ง **Rtc by Makuna** ผ่าน Library Manager
2. อัปโหลด `rtc-test.ino` เปิด Serial Monitor ที่ **115200 baud** และตั้ง Line Ending เป็น **Newline** หรือ **Both NL & CR**
3. ส่งคำสั่งรูปแบบ `s YYYY-MM-DD HH:MM:SS` โดยแทนวันที่และเวลาด้วยเวลาจริงที่ต้องการ เช่น `s 2026-11-15 14:30:00` สเก็ตช์รองรับปี 2000–2099 และพิมพ์เวลาที่อ่านได้ทุกวินาที
4. เช็กว่าเวลาที่แสดงเดินต่อเนื่อง ใส่แบตสำรองตามชนิดที่ระบุสำหรับโมดูล แล้วตัดไฟหลักของ RTC จริงประมาณ 30–60 วินาที เช่น ถอด USB และแหล่งจ่ายอื่นที่ยังเลี้ยง RTC อยู่ โดยให้แบตสำรองคงอยู่
5. ต่อไฟกลับแล้วดูเวลาใน Serial Monitor ทันที **ก่อนส่งคำสั่งตั้งเวลาใหม่** ถ้าเวลาคลาดจากเวลาที่ควรเป็นเพียงเล็กน้อยและเดินต่อจากช่วงที่ปิดไฟ ถือว่าผ่าน สเก็ตช์จะอ่านเวลาเดิมเสมอเมื่อบูต

ถ้าขึ้น `Invalid RTC time` ให้ตรวจไฟ กราวด์ และสาย CLK/DAT/RST แล้วลองตั้งเวลา ถ้าเวลาหายหรือหยุดหลังตัดไฟหลัก ให้เช็กแบตสำรอง ขั้ว และหน้าสัมผัส
