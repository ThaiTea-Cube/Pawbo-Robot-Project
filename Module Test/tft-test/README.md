# ทดสอบจอ TFT SPI สองจอ

สเก็ตช์นี้ตั้งค่าสำหรับจอ 1.54 นิ้วที่คาดว่าใช้ **ST7789 ขนาด 240×240** ตามรหัสที่แจ้งและผัง Massmore ใช้ SPI ร่วมกัน แล้วเลือกจอด้วย `CS` คนละขา จึงวาดคนละภาพได้

## ต่อสายกับ Massmore ESP32

ปิดไฟก่อนต่อสาย ดูชื่อขาบนจอแต่ละตัวก่อนเสียบ

| ขาบนจอ | จอ 1 | จอ 2 |
| --- | --- | --- |
| `GND` | `GND` | `GND` ร่วมกัน |
| `VCC` | `3V3` | `3V3` |
| `SCL` | `GPIO18` | `GPIO18` |
| `SDA` | `GPIO23` | `GPIO23` |
| `RST` | `GPIO4` | `GPIO4` |
| `DC` | `GPIO2` | `GPIO2` |
| `CS` | `GPIO32` | `GPIO33` |
| `BL` | `3V3` หากโมดูลระบุว่า BL รับ 3.3V แบบ active-high | เช่นเดียวกับจอ 1____ |

ขา `SCL` และ `SDA` บนจอชุดนี้คือ SPI Clock และ MOSI ตามลำดับ ใช้สายจัมเปอร์แยกตามตาราง ขา `CS` ของสองจอต้องแยกกัน GPIO32/33 มีที่หัว `Servo2/Servo3` ของ Massmore ให้ใช้เฉพาะ **ขาสัญญาณ** ของหัวเหล่านี้ และใช้ขา `3V3` ของบอร์ดจ่ายไฟให้จอ หากสเปกขา `BL` ระบุว่าเป็นขา LED โดยตรง ให้ต่อตามวงจรจำกัดกระแสของโมดูล

## อัปโหลดและดูผล

1. ใน Library Manager ติดตั้ง **Adafruit ST7735 and ST7789 Library** และ **Adafruit GFX Library** รวมถึง dependencies ที่ Arduino IDE เสนอ
2. เปิด `tft-test.ino` เลือกบอร์ด ESP32 กับพอร์ต USB แล้วอัปโหลด เปิด Serial Monitor ที่ **115200 baud**
3. เมื่อมองจากด้านหน้าหุ่นยนต์ ให้จอ 1 อยู่ซ้ายและจอ 2 อยู่ขวา แต่ละจอแสดงตาหลักสีแดงหนึ่งตากับตาเล็กสามตาบนลายใยแมงมุม ตาหลักสองข้างจะเรืองแสงพร้อมกัน โค้ดใช้ `TFT_ROTATION = 2` เพื่อหมุนภาพทั้งสองจอ 180°
4. ถ้าดำทั้งคู่ ให้เช็กไฟ `VCC`, `BL`, กราวด์ และขาร่วมก่อน ถ้าขึ้นเพียงจอเดียว ให้เช็ก `CS` ของจอนั้นและลองสลับจอหลังปิดไฟ ถ้าทั้งสองจอแสดงลายตาเอียงไปด้านเดียวกัน ให้เช็กว่าสาย `CS` ไปคนละ GPIO

ข้อความ `Spider eyes drawn at 180 degrees` ใน Serial Monitor ยืนยันว่า ESP32 ส่งคำสั่งวาดแล้ว ให้ดูภาพบนจอจริงเพื่อยืนยันผล
