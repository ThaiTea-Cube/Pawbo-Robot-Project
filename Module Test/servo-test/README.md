# ทดสอบเซอร์โว 8 ตัวด้วย ESP32 และ PCA9685

สเก็ตช์นี้ใช้ทดสอบเซอร์โวแบบกำหนดตำแหน่งบนช่อง CH0–CH7 ของ PCA9685 ค่าเริ่มต้นใช้ I²C ที่ `0x40` และ PWM 50 Hz

## ต่อสาย

| PCA9685 | ต่อกับ |
| --- | --- |
| VCC | 3.3V ของ ESP32 |
| GND | GND ของ ESP32 และขั้วลบของแหล่งจ่ายเซอร์โว |
| SDA | GPIO21 ของ ESP32 |
| SCL | GPIO22 ของ ESP32 |
| V+ | ขั้วบวกของแหล่งจ่ายแยก ใช้แรงดันและกระแสตามสเปกเซอร์โว |
| CH0–CH7 | เซอร์โวตัวที่ 1–8 ตามลำดับ ตรวจตำแหน่งสายสัญญาณ ไฟ และ GND จากป้ายบนบอร์ด |

ปิดไฟก่อนเสียบสาย ใช้ USB จ่ายไฟให้ ESP32 และใช้แหล่งจ่ายแยกที่ V+ สำหรับเซอร์โว หากใช้ ESP32 รุ่นที่ต่อ I²C คนละขา ให้แก้ `SDA_PIN` และ `SCL_PIN` ในสเก็ตช์ หากบอร์ด PCA9685 ตั้งจัมเปอร์ที่อยู่ไว้ ให้แก้ `PCA_ADDRESS` ให้ตรงกัน

ทดสอบครั้งแรกโดยถอดแขนเซอร์โวออกจากกลไกขาหุ่นยนต์ ตรวจว่าสเปกเซอร์โวรองรับ 50 Hz และช่วงพัลส์ 1000–2000 µs หรือปรับ `PWM_HZ` และ `PULSES_US` ให้ตรงรุ่นก่อนจ่ายไฟ

## อัปโหลดและทดสอบ

1. เปิด `servo-test.ino` ใน Arduino IDE ติดตั้ง **esp32 by Espressif Systems** ผ่าน Boards Manager
2. ติดตั้ง **Adafruit PWM Servo Driver Library** ผ่าน Library Manager พร้อม dependencies ที่ IDE เสนอ
3. เลือกบอร์ดและพอร์ตของ ESP32 แล้วอัปโหลด เปิด Serial Monitor ที่ **115200 baud** หากพลาดข้อความเริ่มต้น ให้กดปุ่ม EN/RESET บนบอร์ด
4. ส่ง `0` เพื่อทดสอบ CH0 หรือส่ง `a` เพื่อวนทดสอบ CH0–CH7 พร้อมกันต่อเนื่อง ส่ง `x` เพื่อยกเลิกและปิด PWM ทั้ง 8 ช่อง ส่ง `?` เพื่อดูคำสั่ง
5. แต่ละตัวควรเริ่มที่กลาง ขยับสองทิศ แล้วกลับกลาง ตามลำดับพัลส์ 1500 → 1000 → 2000 → 1500 µs โหมด a จะวนต่อโดยค้างตำแหน่งกลางหนึ่งจังหวะระหว่างรอบ ส่วนโหมด 0–7 จะทดสอบหนึ่งรอบแล้วปิด PWM ของช่องนั้น หากมีตัวใดขยับไม่ครบ ให้ส่งเลขช่อง 0–7 เพื่อทดสอบแยก

ข้อความ `sequence complete` แสดงว่าส่งคำสั่งครบ ต้องดูการเคลื่อนจริงเพื่อยืนยันว่าเซอร์โวผ่าน ถ้าขึ้น `PCA9685 not responding` ให้ตรวจไฟ VCC สาย I²C และที่อยู่ ถ้าพบ PCA9685 แต่เซอร์โวทุกตัวนิ่ง ให้ตรวจไฟ V+ กราวด์ร่วม และขา OE (ถ้าบอร์ดมี ขานี้ต้องเป็น LOW เพื่อเปิดเอาต์พุต) ถ้านิ่งเพียงตัวเดียว ให้ปิดไฟแล้วสลับกับเซอร์โวที่ขยับได้เพื่อแยกว่าเป็นที่ตัวเซอร์โวหรือช่องบนบอร์ด
