# รายการทดสอบโมดูล Pawbo

ติ๊กเมื่อทดสอบกับอุปกรณ์จริงและผ่านตามรายการ

- [ ] **Servo Motor (8 ตัว)** — ทดสอบผ่าน ESP32 + PCA9685 ช่อง CH0–CH7 ให้แต่ละตัวขยับสองทิศและกลับตำแหน่งกลาง ดู [วิธีต่อสายและอัปโหลด](servo-test/README.md)
- [x] **ลำโพง** — เล่นเสียงทดสอบและตรวจว่าได้ยินชัด
- [ ] **Touch Sensor** — ตรวจสถานะตอนแตะและปล่อย และนับหนึ่งครั้งต่อการแตะ ดู [วิธีต่อสายและทดสอบ](touch-test/README.md)
- [ ] **RTC Module** — ตั้งเวลา อ่านกลับ และตรวจว่าเวลาเดินต่อหลังตัดไฟหลัก ดู [วิธีต่อสายและทดสอบ](rtc-test/README.md)
- [ ] **TFT SPI (2 จอ)** — ตรวจภาพตาแมงมุมซ้าย–ขวาในแนว 180° และจังหวะเรืองแสงพร้อมกัน ดู [วิธีต่อสายและอัปโหลด](tft-test/README.md)
