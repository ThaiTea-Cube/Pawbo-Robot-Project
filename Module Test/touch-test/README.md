# ทดสอบ Touch Sensor กับ ESP32

สเก็ตช์ตั้งต้นสำหรับโมดูลสัมผัสแบบดิจิทัล 3 ขา เช่น **TTP223** ที่ใช้ไฟ 3.3V และตั้งเป็นโหมดแตะติด ปล่อยดับ (Direct)

## ต่อสายกับ Massmore

| ขาบนเซ็นเซอร์ | ขาบน Massmore ESP32 |
| --- | --- |
| `VCC` / `VDD` | `3V3` |
| `GND` | `GND` |
| `OUT` / `SIG` / `I/O` | ขาสัญญาณ `IO7 / GPIO35` |

ปิดไฟก่อนต่อสาย เช็กลำดับขาจากป้ายบนโมดูล ใช้ไฟ 3.3V เพื่อให้ระดับสัญญาณออกตรงกับ ESP32 ขา GPIO35 เป็นอินพุตและไม่มีตัวต้านทานดึงขึ้นหรือลงภายใน จึงต้องต่อกับเอาต์พุตของเซ็นเซอร์ก่อนทดสอบ

## อัปโหลดและตรวจผล

1. เปิด `touch-test.ino` ใน Arduino IDE เลือกบอร์ด ESP32 และพอร์ตแล้วอัปโหลด ใช้ไลบรารีที่มากับชุดบอร์ดได้เลย
2. เปิด Serial Monitor ที่ **115200 baud** กด EN/RESET และอย่าแตะแผ่นเซ็นเซอร์ระหว่างเริ่มทำงาน ควรเห็น `Ready. Initial state: RELEASED`
3. แตะแล้วปล่อย 3 ครั้ง ควรได้ `TOUCH` หนึ่งครั้งตอนแตะ และ `RELEASE` หนึ่งครั้งตอนปล่อย ตัวนับเพิ่มเฉพาะตอนแตะและควรจบที่ 3
4. ลองแตะค้าง 1–2 วินาที ตัวนับควรเพิ่มครั้งเดียว จากนั้นปล่อยแล้วตรวจว่าได้ `RELEASE`

ถ้าข้อความแตะกับปล่อยสลับกัน ให้เปลี่ยน `TOUCH_ACTIVE_LEVEL` เป็น `LOW` ถ้าเซ็นเซอร์เปลี่ยนสถานะเมื่อแตะครั้งถัดไปและค้างหลังยกนิ้ว ให้ตรวจว่าตั้งโหมด Direct หรือ Toggle ตามคู่มือของโมดูล
