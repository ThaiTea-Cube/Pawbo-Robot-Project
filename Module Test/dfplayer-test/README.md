# ทดสอบเสียงหมาด้วย DFPlayer Mini

## ต่อสายกับ ESP32 บน Massmore 38-pin

ปิดไฟก่อนต่อสาย ใช้ขาสัญญาณของหัว IO2 และ IO4 ตามป้ายบน Massmore

| ขา DFPlayer Mini | ต่อกับ |
| --- | --- |
| `VCC` | แหล่งจ่าย 5V ที่จ่ายไฟให้โมดูลและลำโพงได้ |
| `GND` | กราวด์ของแหล่งจ่ายและ GND ของ ESP32 |
| `TX` | `GPIO13 / IO2` ของ ESP32 |
| `RX` | `GPIO14 / IO4` ของ ESP32 ผ่านตัวต้านทาน 1 kΩ อนุกรม |
| `SPK1`, `SPK2` | สายลำโพงคนละขั้ว ใช้ลำโพงที่รองรับเอาต์พุตของ DFPlayer |

ต่อสายลำโพงทั้งสองเส้นเข้ากับ `SPK1` และ `SPK2` โดยตรง ห้ามต่อขาลำโพงข้างใดข้างหนึ่งลง GND

## เตรียมการ์ดและเล่นเสียง

1. วางไฟล์ [0001.mp3](../dfplayer-audio/mp3/0001.mp3) ที่หน้าแรกของ microSD แบบ FAT32 ให้ได้พาธ `/0001.mp3` แล้วใส่การ์ดก่อนจ่ายไฟ คำสั่ง `play(1)` เล่นตามลำดับไฟล์ที่โมดูลอ่านจากการ์ด สำหรับการทดสอบให้มีไฟล์เสียงนี้เพียงไฟล์เดียวบนการ์ด
2. ติดตั้งไลบรารี **DFRobotDFPlayerMini** ของ DFRobot ผ่าน Library Manager ใน Arduino IDE
3. เปิด `dfplayer-test.ino` เลือกบอร์ดและพอร์ต ESP32 แล้วอัปโหลด สเก็ตช์เล่นเสียงหนึ่งครั้งเมื่อเริ่มทำงานที่ระดับเสียง 8/30
4. เปิด Serial Monitor ที่ **115200 baud** ส่ง `p` เพื่อเล่นซ้ำ `x` เพื่อหยุด และ `+` หรือ `-` เพื่อปรับระดับเสียงทีละขั้น

ถ้าขึ้น `DFPlayer init failed` ให้ตรวจไฟ 5V กราวด์ร่วม และการไขว้สาย TX/RX รวมถึงการ์ด แล้วกด EN/RESET บน ESP32 ถ้าโมดูลตอบสนองแต่ไม่มีเสียง ให้ตรวจชื่อไฟล์และสายลำโพงที่ SPK1/SPK2
