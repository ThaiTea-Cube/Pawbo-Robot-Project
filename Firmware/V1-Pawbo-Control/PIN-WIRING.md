# ผังต่อสาย PAWBO V1

สำหรับ **Massmore ESP32 38-pin** กับเฟิร์มแวร์ `PawboControl` ให้ยึดหมายเลข GPIO และใช้ชื่อหัวบน Massmore ในวงเล็บช่วยหา pin ปิดไฟทุกแหล่งก่อนต่อสาย

## สายสัญญาณทั้งหมด

| ขา Massmore ESP32 | ต่อกับ | รายละเอียด |
| --- | --- | --- |
| GPIO2 | TFT จอซ้าย → `DC` | |
| GPIO4 | TFT จอซ้าย → `RST` / `RES` | |
| GPIO13 (`IO2`) | DFPlayer Mini → `TX` | DFPlayer TX ส่งเข้า ESP32 RX |
| GPIO14 (`IO4`) | DFPlayer Mini → `RX` | ESP32 TX ส่งผ่านตัวต้านทาน **1 kΩ อนุกรม** |
| GPIO16 (`RX2` บน ESP32 บางรุ่น) | TFT จอขวา → `RST` / `RES` | |
| GPIO17 (`TX2` บน ESP32 บางรุ่น) | TFT จอขวา → `DC` | |
| GPIO18 | TFT จอซ้าย → `SCL` / `SCK` | SPI clock |
| GPIO19 | TFT จอขวา → `SCL` / `SCK` | SPI clock |
| GPIO21 | PCA9685 → `SDA` | I²C data |
| GPIO22 | PCA9685 → `SCL` | I²C clock |
| GPIO23 | TFT จอซ้าย → `SDA` / `MOSI` | SPI data |
| GPIO25 (`IO1`) | ปุ่มซ้าย → ขาสัญญาณ | อีกขาของปุ่มลง GND |
| GPIO26 | TFT จอขวา → `SDA` / `MOSI` | SPI data |
| GPIO27 (`M1_IN1`) | ปุ่มขวา → ขาสัญญาณ | อีกขาของปุ่มลง GND |
| GPIO32 (หัว `Servo2`) | TFT จอซ้าย → `CS` | ใช้เฉพาะขาสัญญาณของหัว |
| GPIO33 (หัว `Servo3`) | TFT จอขวา → `CS` | ใช้เฉพาะขาสัญญาณของหัว |
| GPIO35 (`IO7`) | Touch Sensor → `OUT` / `SIG` | TTP223 แบบ Direct, แตะแล้วสัญญาณ HIGH |

จอสองจอใช้ SPI คนละชุด ถ้าเปลี่ยนจากผังเดิม ให้ย้ายสาย **SCK, MOSI, RST และ DC ของจอขวา** ไปยัง GPIO ใหม่ตามตาราง GPIO16/17 ใช้กับ ESP32-WROOM-32 ที่เปิดขาเหล่านี้บนหัวเสียบ ถ้าหัว Massmore ไม่มีเลขกำกับ ให้ดูหัวของโมดูล ESP32 โดยตรง หลีกเลี่ยงใช้ GPIO26 กับวงจรอื่นพร้อมจอขวา

ใช้รางไฟและกราวด์บนเบรดบอร์ดหรือหัวจ่ายไฟแยกเพื่อเสียบสายไฟทีละเส้นได้โดยไม่บัดกรี


ซ้ายและขวาอ้างอิงจากมุมมองด้านหน้าหุ่น ใช้ปุ่มกดแบบปกติเปิด เฟิร์มแวร์เปิด pull-up ให้แล้ว ถ้าเคยต่อ GPIO25 กับแอมป์หรือ GPIO27 กับวงจรมอเตอร์ ให้ถอดสายวงจรเดิมก่อนใช้เป็นปุ่ม

## ไฟเลี้ยง กราวด์ และอุปกรณ์ปลายทาง

| จุดต่อ | ต่อกับ |
| --- | --- |
| TFT ทั้งสองจอ `VCC` และ Touch `VCC` / `VDD` | `3V3` ของ Massmore |
| TFT ทั้งสองจอ `BL` / `BLK` | `3V3` เฉพาะโมดูลที่ระบุว่าขานี้รับสัญญาณ 3.3 V แบบ active-high ถ้าเป็นขา LED โดยตรงให้ต่อตามวงจรของโมดูล |
| PCA9685 `VCC` | `3V3` ของ Massmore สำหรับวงจรสัญญาณ |
| PCA9685 `V+` | ขั้วบวกของแหล่งจ่าย Servo แยก ใช้แรงดันและกระแสตามสเปก Servo |
| PCA9685 `OE` (ถ้ามี) | ระดับ LOW เพื่อเปิดเอาต์พุต |
| DFPlayer Mini `VCC` | แหล่งจ่าย 5 V |
| DFPlayer Mini `SPK1` และ `SPK2` | ลำโพงคนละขั้ว ห้ามลง GND |
| `GND` ของทุกโมดูล | กราวด์ร่วมกับ Massmore และขั้วลบของแหล่งจ่าย Servo / DFPlayer |

เสียบ Servo **ตัวที่ 1–8** ลงช่อง **CH0–CH7** ของ PCA9685 ตามลำดับ ตรวจตำแหน่ง `SIG`, `V+` และ `GND` จากป้ายบนบอร์ด ใช้ I²C address **0x40** และถอดก้านส่งกำลังออกก่อนลองขยับครั้งแรก

ใส่ไฟล์เสียงแทร็กแรก `/0001.mp3` ใน microSD ของ DFPlayer สำหรับเสียงปลุก Wi‑Fi และ MQTT ใช้ ESP32 โดยตรง
